04间距

硬规则只有一条：必须落在 2px 网格上。在这之上分三档使用——主节奏走 8 的倍数，常规走 4 的倍数，微调只用于图标与文字之间。禁止 p-[7px] 这类任意值。

主节奏 · 8 的倍数
8px · gap-2 · 紧凑元素
16px · p-4 · 卡片内边距
24px · p-6 · 区块分离
32px · p-8 · 页面级留白
64px · mt-16 · 空状态下移
常规 · 4 的倍数
12px · p-3 · 列表项内边距（最常用）
20px · pt-5 · 侧栏顶部留白
40px · pl-10 · 输入框让位给图标
微调 · 仅限图标与文字之间
6px · gap-1.5 · shadcn 按钮内置间距，必须放行
10px · gap-2.5 · 侧栏图标与标签
为什么不做白名单：最初版只允许 8 档，结果把 pt-5、pl-10、mt-16 全判成违规——但它们都是合理值。规范的职责是挡住"随手写"（7px、13px），不是把合理选择也一并禁掉。

08组件状态

每个可交互元素必须有默认、悬停、焦点、禁用四态。焦点环只在键盘操作时出现，鼠标点击不出现。

变体默认悬停禁用用途
default 整屏唯一主操作
outline 并列的次操作
ghost 导航项、弱化操作
destructive 不可恢复操作
焦点演示：用 Tab 键依次聚焦上面任意按钮，应出现 3px 不透明 ring 外环（对比度 ≥ 3:1）。鼠标点击时不应出现。
为什么不半透明：shadcn 默认是 ring-ring/50，实测在浅色底上只有约 1.3:1，键盘用户看不见。--ring 已从 oklch(0.708) 调深到 oklch(0.55)，并去掉 50% 透明度，实测达到 3.6:1。

09光标预览面

本产品专属规格。光标多为透明 PNG，纯灰底会让白色光标消失，因此预览底必须是棋盘格；对比度压到 4% 以内，避免抢戏。

棋盘格（推荐）
纯色底（白光标会丢）
格子尺寸8px / 4px 交错
格子对比ΔL ≈ 4%
卡片内尺寸h-16 (64px)
槽位内尺寸h-12 (48px)
光标图最大边48px

10动效

四档时长，两条曲线。只动透明度、位移、缩放与阴影，不动宽高（会触发重排）。

档位时长曲线用于
fast120msease-standard悬停变色、焦点环、按下
base180msease-standard选中态切换、卡片描边、堆叠让位
slow240msease-standard弹窗、Toast 入场
exit160msease-exit弹窗、Toast 退场（比入场快 1/3）
组件进入退出状态切换
Toast下移 8px + 0.96 → 1，240ms下沉 4px + 0.98，160ms堆叠让位 180ms
弹窗0.96 → 1 + 淡入，240ms缩回 0.96，160ms遮罩 180ms / 160ms
控件——按钮/输入 120ms，卡片 180ms
禁用 transition-all：它会连布局属性一起过渡，视觉上发飘，性能上掉帧。改为明确列出 opacity / translate / scale / box-shadow。
完整范围（含故意不做的项及理由）、`prefers-reduced-motion` 降级与逐帧验收，见 docs/motion.md。

12落地检查

每次改动界面后跑这四条，全绿才算完成。design_check 与 motion_check 需要 vite 在 1420 运行，另外两条只扫源码。

node scripts/design_check.mjs自动按 Tab 走一遍，查焦点环、aria 与结构，并存截图
node scripts/design_audit.mjs看间距/字号/图标是否出现阶梯外的值
node scripts/ui_ratio.mjs看 shadcn 与原生标签的比例是否合理
node scripts/motion_check.mjs逐帧采样：进出场时长、中间态、减少动态是否生效
