## 鼠标主题工具 v0.2.0

一个**不需要管理员权限**的 Windows 光标主题管理器：导入主题 → 一键应用 → 管理 → 回溯上次用的那个。

v0.2.0 把删除变成可恢复的回收站，补齐批量导入、备份历史与诊断中心，并支持跟随系统深浅色自动切换主题；导入、迁移与读取链路也做了安全加固。

### ✨ 本版亮点

- **界面重构**：拆成「主题图库」（分组网格）/「我的主题」（数据表）/「最近使用」（时间轴）三个内容视图 + 设置管理面板；右侧检查器按页显示（最近使用不挂检查器），三页各自记住选中的主题
- **文件夹导入**：除 `.zip` 外，整个主题文件夹也能直接拖进窗口导入（与 zip 共用同一条链路；侧栏选择对话框仍只收 `.zip`）；文件夹里的链接 / 目录联接会跳过并说明原因
- **`.inf` 槽位映射**：主题包内带 `.inf` 安装说明时，15 个槽位按说明书对号，优先于文件名推断；没带或解析失败才退回标准命名，不会缺槽位
- **回收站**：删除主题改为移入回收站，可随时恢复；支持彻底删除与清空。上限 20 套 / 512 MB，超出按删除时间自动清理最早的条目，删除结果会说明清了几套；正在使用的主题仍不能删除，损坏条目列出但不可恢复
- **跟随系统自动切换主题**：「设置 → 通用 → 外观」开启后，分别指定系统浅色 / 深色时使用的主题；系统深浅色变化或窗口回到前台时自动应用。手动「还原系统默认」后自动切换暂停，直到系统深浅色再次翻转；映射的主题被删除时静默跳过，并在下拉框提示改选
- **维护界面**：
  - **诊断中心**（设置 → 数据）：只读体检报告，一键复制，不提供自动修复
  - **备份历史**（设置 → 数据）：应用内备份保存到 `backups\`，可恢复或清理；恢复是合并式，只补缺失、不覆盖本地已有主题；损坏的备份保留可见，但不可恢复
  - **导入中心**（侧栏「批量导入」或一次拖入多个）：串行逐个导入，失败项可单独重试
- **系统改写检测与夺回**：系统「鼠标指针样式」设置可能整体改写 15 个槽位。状态卡新增「光标已被系统设置修改」提示；重新应用任意主题或「还原系统默认」即可夺回，「还原系统默认」现在随时可用，并清理 Win11 新指针键的残留
- **全新安装器**：NSIS 安装包改为整窗自绘五页（欢迎 / 已安装维护 / 安装选项 / 进度 / 完成），常驻侧栏步骤高亮；仍是当前用户安装、全程无 UAC。MSI 现在也能用中文产品名正常构建（企业分发备用）

### 🔧 改进与修复

- **主题路径相对化**：`theme.json` 与备份内只存相对主题目录的路径，迁移、备份恢复后不会因盘符或目录变化指错文件
- **主题目录迁移更安全**：目标校验 → 暂存复制 → 逐文件校验 → 原子切换，失败回滚；源目录只在全部成功后删除
- **重操作后台执行**：导入、备份、恢复、目录迁移、删除与回收站操作都在后台执行并显示阶段进度，界面不再卡住；同一时间只允许一个重操作，避免互相踩目录
- **读取与校验加固**：主题包与备份有明确的体积、条目上限，超限会清理临时文件并给出可照着处理的中文原因；`.inf` 支持按 BOM 识别的 UTF-16LE / BE 与 UTF-8，无 BOM 时按宽松 UTF-8 解码；前端传入的路径、槽位与 UUID 在后端统一复核
- **安全基线**：CSP 与文件对话框权限收窄，外链只允许 GitHub 域名
- **稳定性**：设置与历史读取兼容旧文件；修复预览缓存锁在异常状态下的失效风险
- **交互细节**：空状态、加载骨架与错误提示统一；Toast 增加剩余时间进度条，悬停 / 失焦时与计时器同步暂停

### ❓ 常见问题

**Q：安装后系统光标没变化？**
A：光标切换只在**桌面版程序**里生效，浏览器里看不到效果。本应用通过 `HKCU` 写槽位路径 + `SPI_SETCURSORS` 通知系统刷新，不写 `C:\Windows\Cursors`，无需管理员权限。个别软件会缓存光标，注销重登或重启该软件即可。

**Q：删除的主题还能找回吗？**
A：能。删除只是移入「设置 → 数据 → 回收站」，可恢复或彻底删除。回收站上限 20 套 / 512 MB，超出会自动清理最早的条目；恢复后的主题落到当前主题存储目录，换过存储目录也能找回。

**Q：光标为什么会被系统改回去？**
A：Windows 的「鼠标指针样式」设置会把 15 个经典槽位整体改写，本应用无法阻止，但会在窗口回到前台时检查，并在状态卡提示「光标已被系统设置修改」。重新应用任意主题或「还原系统默认」即可夺回。本应用不写系统的「已保存方案」列表，经典鼠标属性面板显示「(无)」是正常现象。

**Q：自动切换主题没生效？**
A：确认「设置 → 通用 → 外观」里的开关已打开，且为要生效的模式选了主题（只配一侧时，另一侧保持当前光标）；应用需要保持运行（最小化到托盘也可以），若系统切换时窗口在后台，回到前台会补一次检查。手动点过「还原系统默认」后，自动切换会暂停，直到系统深浅色再次翻转；映射的主题被删除时会跳过，下拉框会提示改选。

**Q：我的数据存在哪？卸载会删吗？**
A：主题在 `%LOCALAPPDATA%\CursorStudio\themes\<uuid>\`，回收站在 `trash\`，应用内备份在 `backups\`，历史在 `history.json`。**卸载不删数据**，重装后还在；主题存储目录也可以在「设置 → 通用」里换到别处。

**Q：别人没装这个软件，怎么用我分享的主题？**
A：「导出」得到的 `.zip` 里自带一份 `.inf`：解压后右键该文件 →「安装」。装完在系统「鼠标设置」里选一次该方案（或注销重登）即生效。

**Q：支持 macOS / Linux 吗？**
A：不支持。本应用依赖 Windows 注册表与光标 API，只在 Windows 上构建与运行。
