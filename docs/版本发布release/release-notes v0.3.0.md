## 鼠标主题工具 v0.3.0

一个**不需要管理员权限**的 Windows 光标主题管理器：导入主题 → 一键应用 → 管理 → 回溯上次用的那个。

v0.3.0 把光标来源、备份可信度与日常维护补齐：`.theme` / `.themepack` 官方格式直接收编，外部改写的光标可以一键接管，备份能先看内容、只恢复一套、还能逐份体检；同时加入光标守护、定时切换、托盘快速切换与主题查重。

### ✨ 本版亮点

- **接管外部光标**：系统设置或其它工具改过光标时，侧栏「当前使用」卡会出现「保存并应用」——把当前 15 个槽位复制成一套「我的主题」并立即应用。全部槽位抄全才自动应用；有槽位没抄全时只保存并说明原因，不会把你当前的光标写坏
- **光标守护**：可选开启（默认关闭）。启动时、或检测到光标被系统改写后，自动恢复上次使用的主题；只在应用运行且目标仍在主题库时生效，不抢你手动还原的默认状态
- **托盘快速切换**：关闭到托盘后，托盘菜单直接列出最近使用的主题（最多 8 个，当前主题置顶勾选）与「还原默认光标」，不展开窗口也能换
- **Windows 主题资产直接收**：
  - **`.theme` 光标方案**：Windows 个性化保存的方案文件、主题站分发的方案直接拖进来，按 `[Control Panel\Cursors]` 段对号 15 个槽位；引用系统光标或包外文件也可收编（复制，不动源文件）
  - **`.themepack` 主题包**：微软官方分装的 CAB 容器直接认，包内 `.theme` 方案优先于文件名推断；壁纸 / 声音等非光标内容不处理
  - 右键菜单同步覆盖 `.zip` / `.themepack` / `.theme` 三类文件，一键送给应用导入
- **备份从「能恢复」到「可验证、可精准找回」**：
  - **自动备份**：可选每天一份进备份历史，按保留份数自动清理（默认关闭；手动备份不会被清理）
  - **内容浏览**：恢复前先看包里有哪些主题、各有多少槽位 / 文件、缺了什么
  - **单主题恢复**：只把其中一套追加回主题库，不覆盖已有、不合并历史；部分缺文件仍可恢复并提示缺口
  - **完整性体检**：逐份 CRC 校验，坏条目当场点名；结果只在本次会话有效，不会拿旧结论骗人
  - **损坏防护**：恢复遇到坏数据时给出可照着行动的中文错误，并明确「本次恢复已全部撤销」；不做半套恢复
  - **从文件恢复先看内容**：外部备份不再盲合，先看清单再决定逐套恢复还是整包合并
- **定时切换主题**：按时间段自动应用「期间内 / 期间外」主题，支持跨零点窗口；时间段内有配置时优先于深浅色自动切换（默认关闭）
- **主题库维护**：
  - **文件完整性**：声明了但读不到的槽位文件，在「我的主题」、检查器和诊断中心提示「缺 N 个文件」，应用前就能看见；只提示不拦截
  - **内容查重**：按槽位指纹预分组、组内逐字节确认，只报证实的重复，并算出删到每组一套能省多少空间
  - **存储占用**：按主题库 / 备份 / 回收站 / 历史 / 设置分区域统计
  - **批量导出**：一次导出「我的主题」全部套，单套失败不影响其余
  - **清空使用记录**：只清历史事件，不碰主题与设置

### 🔧 改进与修复

- **导入链路**：`.inf` / `.theme` 映射认领的文件不再参与文件名推断，避免同一文件被巧合撞进第二个槽位；`.themepack` 的 LZX / Quantum 压缩在动任何文件前就给出明确错误与出路
- **CI 稳定性**：Rust 工具链钉到 1.99.1 并显式安装 clippy，堵住 lint 随发版漂移把在途 PR 打成红；注册表路径两侧统一 `canonicalize`，修掉 runner 上 8.3 短名导致的误判
- **启动竞态**：设置先就绪、主题列表为空时，首次自动切换 / 定时切换评估不再被 `lastAppliedId` 去重吞掉
- **真机验证**：新增 `scripts/real_machine/` 下的隔离验证脚本（`.theme` 方案收编、`.themepack` 导入），碰真实文件系统的路径有据可查
- **文档与口径**：39 个命令、导入入口与数据目录说明全部对齐；发布指南的版本号同步点从四处扩为五处（含 `package-lock.json` 根版本）

### ❓ 常见问题

**Q：安装后系统光标没变化？**
A：光标切换只在**桌面版程序**里生效，浏览器里看不到效果。本应用通过 `HKCU` 写槽位路径 + `SPI_SETCURSORS` 通知系统刷新，不写 `C:\Windows\Cursors`，无需管理员权限。个别软件会缓存光标，注销重登或重启该软件即可。

**Q：系统设置把我的光标改回去了，能自动恢复吗？**
A：可以。打开「设置 → 通用 → 光标守护」后，应用启动或检测到外部改写时会恢复上次使用的主题。守护默认关闭；需要登录后恢复时，再配合「开机自启动」一起开。

**Q：`.theme` / `.themepack` 导入后为什么少了几个槽位？**
A：方案里引用的文件可能不存在、不是光标格式，或指向了当前机器没有的系统光标。缺失的槽位会跳过并在导入结果里点名，其余槽位照常收编；如果所有槽位都落空，导入会被拒绝并清理半成品目录。

**Q：`.themepack` 为什么提示打不开？**
A：本版支持 Windows 主题包常用的 MSZIP 压缩；LZX / Quantum 压缩的罕见老包暂不支持，会直接说明原因，不会静默失败。可以先用系统「主题设置」安装一次，再用「保存并应用」接管当前光标。

**Q：备份坏了怎么办？**
A：在「设置 → 数据 → 备份历史」里点该备份的「体检」，CRC 校验会指出坏在哪里。损坏的备份在整包恢复与单主题恢复里都会被拒绝，并保证本次恢复全部撤销；请换一份备份或重新做一份。

**Q：删除的主题还能找回吗？**
A：能。删除只是移入「设置 → 数据 → 回收站」，可恢复或彻底删除。回收站上限 20 套 / 512 MB，超出会自动清理最早的条目；恢复后的主题落到当前主题存储目录，换过存储目录也能找回。

**Q：我的数据存在哪？卸载会删吗？**
A：主题在 `%LOCALAPPDATA%\CursorStudio\themes\<uuid>\`，回收站在 `trash\`，应用内备份在 `backups\`，历史在 `history.json`。**卸载不删数据**，重装后还在；主题存储目录也可以在「设置 → 通用」里换到别处。

**Q：别人没装这个软件，怎么用我分享的主题？**
A：「导出」得到的 `.zip` 里自带一份 `.inf`：解压后右键该文件 →「安装」。装完在系统「鼠标设置」里选一次该方案（或注销重登）即生效。

**Q：支持 macOS / Linux 吗？**
A：不支持。本应用依赖 Windows 注册表与光标 API，只在 Windows 上构建与运行。
