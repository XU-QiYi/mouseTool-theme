# Stitch UI 提示词 - 鼠标光标主题管理工具

## 设计提示词

```
设计一个 Windows 风格的鼠标光标主题管理工具界面，采用现代简约设计风格。

## 整体布局
- 应用窗口尺寸：1200 x 800px
- 左侧导航栏 + 右侧内容区的经典桌面应用布局
- 深色/浅色两种主题模式支持

## 左侧导航栏
- 宽度：220px
- 顶部：应用 Logo + "鼠标主题工具" 标题
- 菜单项：
  - 🎨 主题库（当前选中态）
  - ➕ 导入主题
  - ✏️ 自制方案
  - ⚙️ 设置
- 底部：当前主题状态指示

## 右侧主内容区 - 主题库页面

### 顶部工具栏
- 页面标题："我的主题库"
- 右侧操作按钮组：
  - 导入主题按钮（主按钮，蓝色）
  - 新建方案按钮（次按钮）
  - 搜索框

### 主题卡片网格
- 布局：3列网格，每项卡片宽度约 320px
- 卡片设计：
  - 圆角 12px，轻微阴影
  - 顶部：主题缩略图预览区（显示鼠标光标集合预览）
  - 中部：主题名称 + 光标数量标签
  - 底部：导入日期 + 操作按钮（应用/预览/删除）
  - 左上角：动态光标角标（如果包含 .ani 文件）
  - 右上角：当前使用中标签（应用后的主题）

### 右侧预览面板（可收起）
- 宽度：350px
- 标题："主题预览"
- 光标状态网格（2列）：
  - 普通选择（Arrow）
  - 忙碌（Wait）
  - 后台工作（AppStarting）
  - 文本选择（IBeam）
  - 链接选择（Hand）
  - 精确选择（Cross）
  - 移动（SizeAll）
  - 不可用（No）
- 每个状态项：
  - 光标图标预览（48x48px）
  - 状态名称标签
  - 动态光标显示为静态预览 + "动态"角标

### 底部操作栏
- 选中主题时显示：
  - "应用此主题" 按钮（醒目，渐变蓝色）
  - "恢复系统默认" 链接按钮

## 导入主题页面
- 拖拽上传区域（虚线边框，支持 .zip 和文件夹）
- 或点击选择文件按钮
- 导入进度条
- 导入历史列表

## 自制方案编辑页面
- 方案名称输入框
- 光标槽位网格（4列）
  - 每个槽位：图标 + 状态名称 + 上传/替换按钮
  - 已上传的显示缩略图，可点击预览
  - 未指定的显示虚线框 + "+" 图标
- 底部：保存方案按钮

## 设计规范
- 配色：遵循 Windows 11 Fluent Design 风格
  - 主色：#0078D4（蓝色）
  - 背景：#F3F3F3（浅色模式）/ #202020（深色模式）
  - 卡片：#FFFFFF / #2D2D2D
- 字体：思源黑体 / 微软雅黑
- 图标风格：线条型，与 Windows 11 风格一致
- 动效：悬停卡片轻微上浮 + 阴影加深

## 交互状态
- 选中态：卡片边框高亮蓝色
- 悬停态：卡片阴影增强
- 加载态：骨架屏占位
- 空状态：居中显示"暂无主题，点击导入"提示
```
