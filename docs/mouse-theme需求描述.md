## 0. 范围

**产品定位**：一个 Windows 桌面小工具，把光标主题管起来——导入、预览、一键应用、随时还原。

**当前范围**

| 能力 | 一句话 |
|---|---|
| 主题聚合 | 系统注册表里已有的光标方案 + 本工具导入的主题，同一屏列出 |
| 导入 | `.zip` 主题包（文件选择器）或整个主题文件夹（拖进窗口）都能导入，自动识别 15 个槽位 |
| 预览 | 静态 `.cur` 与动态 `.ani` 都能在应用内真实播放 |
| 应用 | 一键写入注册表并立即生效，**无需管理员权限** |
| 还原 | 一键回到 Windows 默认光标 |
| 管理 | 重命名、删除、导出为 `.zip` |
| 最近使用 | 记录应用过的主题，最新在前 |
| 设置 | 五分组管理面板（决策 14）：**通用** = 应用主题三态 / 开机自启动 / 关闭行为（直接退出·最小化到托盘）/ 主题存储目录（可搬迁，确认框展示源/目标/数量/大小，执行期锁定并显示进度，失败可重试）/ 自动检查更新；**快捷键** = 应用内快捷键一览与开关；**数据** = 数据目录、备份导出与合并恢复、诊断信息一键复制；**系统集成** = 鼠标属性面板直达 + `.zip` 右键菜单导入（**试点**，真机看效果再定去留，决策 12）；**关于** = 版本 / 开源地址 / 检查更新（GitHub Releases）。设置修改即时生效并持久化 |

**明确不在当前范围**

| 项 | 为什么不做 | 备注 |
|---|---|---|
| 自制方案（逐槽位上图拼一套） | 要新增图片转 `.cur`、热点编辑、方案编辑器三块，成本远高于"导入现成主题"这条主线 | **2026-10-22 拍板不做**（决策 10） |
| 替换单个光标 | 与自制方案同源；槽位卡当前**不可点**，也不做 hover 暗示 | **2026-10-22 拍板不做**（决策 10） |
| 在线主题商店 | 涉及托管、审核、版权，超出工具定位 | 不做 |
| 多语言 / 语言切换 | 后端错误文案、右键菜单、`.inf` 注释均为中文，半吊子 i18n 比没有更伤体验 | 仅简体中文（决策 14，候选设置项中明确不做的一个） |

> 原在本表的「文件夹导入」「解析 `.inf` 槽位映射」两项已于 2026-10-24 转正实现（决策 16 / 决策 15），从本表移出，现状见 §9 与第 2 节。

## 1. 主题来源

| 来源 | 判定 | ID | 能否删除 |
|---|---|---|---|
| 系统方案 | `HKCU\Control Panel\Cursors\Schemes` 下的每个值 | `sys_<方案名>` | 否 |
| 用户主题 | `%LOCALAPPDATA%\CursorStudio\themes\<uuid>\`（可在「设置 → 通用」换成别的目录） | UUID | 是（非使用中时） |

- 三个页面**各是一个独立视图**，不只是同一张列表换个过滤条件：
  - 「主题图库」= 全部方案的分组网格，任务是**逛和挑**；
  - 「我的主题」= 导入方案的表格，能看到槽位覆盖、导入时间，任务是**管**；
  - 「最近使用」= 按自然日分组的时间轴，任务是**回溯**，且不挂右侧检查器。
- 系统方案在**检查器**里标「系统方案」徽章；正在使用的主题在卡片/行内标「使用中」，侧栏底部另有常驻的「当前光标」状态卡。
- **「正在使用」不是界面自己记的**，由后端拿注册表当前光标路径与各主题槽位路径比对得出。识别不出时（系统默认光标、用户手工改过设置）显示为空，不瞎猜。

## 2. 导入

**入口**：侧栏「导入主题」按钮 / Ctrl+O → 系统文件选择器（仅 `.zip`）；**拖放** → 全窗拖入 `.zip` 或整个主题文件夹（决策 16）。

**流程**

1. 来源分流（决策 16）：文件夹直接递归扫描；压缩包先校验再**流式**解压到临时目录（每次 64KB，不整个读进内存）。两条通路共用 `THEME_LIMITS`（决策 18）：解压总量 **50MB**、单文件 **20MB**、最多 **512 个条目**、目录最多 **8 层**；文件夹按光标文件总量与递归深度计。条目名必须通过白名单（拒绝 `..`、盘符、控制 / 非法字符、Windows 保留名）；任何超限立即失败、说明原因，并清理临时目录与半成品主题目录。
2. 扫描 `.cur` / `.ani`（含 `.ico`），包里带 `.inf` 时先按说明书映射槽位（决策 15），剩余槽位按文件名推断（先精确短名，再关键字包含）。
3. 落盘到 `themes/<uuid>/`，写 `theme.json`；**槽位路径只存相对主题目录的路径**（如 `cursors/arrow.cur`），运行时再拼绝对路径——主题目录以后搬到哪都自洽（决策 17）。
4. 列表刷新；新主题在「主题图库」和「我的主题」里都被选中，右侧检查器直接显示它（不强制跳页，也不清掉用户当前的搜索词以外的上下文）。

**失败要能说清原因**（现有文案范式）：

| 情况 | 提示方向 |
|---|---|
| 包里没有光标文件 | 提示"不要把说明文档单独打包" |
| 一个槽位都认不出 | 提示按什么命名，别只说"格式不支持" |
| 包太大 | 给出实际大小与上限（总量 / 单文件） |
| 文件太多或层级过深 | 说明条目数 / 层数上限，提示精简目录后重试 |
| 条目名不合法 | 指出是路径穿越、非法字符还是保留名，整包拒绝 |
| 解压/写盘失败 | 中文主句 + 括号内技术细节 |

**约束**

- 不覆盖同名主题：每次导入都是新 UUID，名称重复不影响。
- 落盘时光标文件**按槽位重命名**（`arrow.cur` / `busy.ani`），同一槽位出现多个文件只取第一个，保证一个槽位一份文件。
- 临时目录在成功或失败后都要清理。
- 槽位来源（2026-10-24 起）：包里带 `.inf` 时按说明书映射，否则按文件名识别；说明书指向的文件不在包里时该槽位也退回文件名（见 §9、决策 15）。
- `.zip` 与整个主题文件夹都能导入（决策 16），流程同一条。

## 3. 预览

| 位置 | 内容 |
|---|---|
| 主题卡 | 封面取槽位列表第一个；槽位按标准顺序排列，正常就是「正常选择」 |
| 详情区 | 4 列网格，只列该主题实际提供的槽位（缺项不占位）；单个文件缺失或损坏时显示占位图 |
| 动态光标 | 逐帧播放，帧间隔取 `.ani` 自带的 rate |

- 预览底必须是**棋盘格**：光标多为透明 PNG，纯色底会让白色光标整个消失。
- `.ani` 由 Rust 解码成帧序列交给前端 canvas 播，**不生成 GIF 文件**（决策 4）。
- 解析失败**不报错、不阻塞**：显示占位图，其余槽位照常显示。

## 4. 应用与还原

**应用**

1. 按 15 个槽位写入 `HKCU\Control Panel\Cursors`（未提供的槽位写空字符串，回落到系统默认），同时写 `SchemeName`，让系统「鼠标设置」里显示当前方案名。
2. 调 `SystemParametersInfoW(SPI_SETCURSORS)` 刷新 —— **只传 `SPIF_SENDCHANGE`**，不带 `SPIF_UPDATEINIFILE`（见决策 2 附注）。
3. 成功后记一条「最近使用」；记录失败不影响光标已切换的事实，但要提示。

> 当前实现只写 `Cursors` 下的槽位值与 `SchemeName`，**不**写 `Cursors\Schemes`。若要补写，需要先想清楚：那个键是系统「鼠标属性」的已保存方案列表，写进去的方案会出现在用户的下拉框里。

- 全程普通用户权限，**不允许出现 UAC 弹窗**。
- 光标文件留在 `%LOCALAPPDATA%` 原地，不复制进 `C:\Windows\Cursors`（决策 2）。
- 目标值 < 500ms。

**还原**：清空各槽位值并同样刷新，回到 Windows 默认。

**已知限制**（不是缺陷，任何第三方主题工具都一样）：UAC 提示框、登录界面、锁屏等**安全桌面**上仍显示系统默认光标。

## 5. 主题管理

| 操作 | 规则 |
|---|---|
| 重命名 | 仅用户主题可改；只改 `theme.json` 里的显示名，**目录名保持 UUID**；`updated_at` 不动（界面承担"导入于"语义）；名称 1–40 字，禁控制字符；值没变不发请求；正在使用的主题改名后，注册表里的 `SchemeName` 要等下次应用才同步 |
| 删除 | 系统方案不可删；使用中的不可删（按钮禁用 + store 拦截 + 后端校验 ID）；二次确认要说清"会连几个光标文件一起删、无法撤销" |
| 导出 | 导出为 `.zip`，包内文件**按槽位命名**（`arrow.cur`、`busy.ani`），保证"导出→再导入"能还原到同一槽位；包内 `theme.json` 同样只写相对路径 |

**存储与迁移**（决策 17）

- 槽位路径在磁盘上一律相对主题目录；旧版本留下的绝对路径仍能读，备份恢复或迁移时自动改写。
- 更换主题存储目录先预检、再确认：确认框展示源目录、目标目录、主题数量与体积；**目标必须为空**，若其中已有同名主题则点名拒绝，**不删除任何文件**。
- 执行期间锁定相关操作并显示阶段进度（复制 → 校验 → 切换 → 重绑注册表 → 保存设置 → 清理）。先写暂存目录、校验通过后原子切换；设置写入或注册表重绑失败会整体回滚，原目录与设置保持原样。
- 迁移成功后才清理原目录；清理失败只提示，不影响使用。正在使用的主题会重绑到新目录的路径，「正在使用」状态不变。
- 备份导出与恢复同样执行相对路径重写：导入备份后即使再换主题目录，预览、应用与「正在使用」仍正确；把备份恢复到新的根目录后功能可用。

## 6. 最近使用

- 存储：`%LOCALAPPDATA%\CursorStudio\history.json`，上限 50 条，同主题去重后置顶。
- 每条只存**名称快照**，不存整份主题：主题被删后历史仍能说清"上次用的是哪个"。
- 被删的主题在时间轴上仍占一条，标「已删除」且不给「再次应用」——它是"什么时候用过什么"的事实，不该因为主题没了就消失。

## 7. 非功能要求

| 类别 | 要求 |
|---|---|
| 兼容性 | Windows 10 / 11，x64（当前构建目标） |
| 窗口 | 默认 1200×800，**最小 1080×640**（再窄三栏会互相挤压）；不做响应式断点：窄窗下不重排、不收起任何一栏，图库网格用 `auto-fill` 自适应列数 |
| 权限 | 全程普通用户，无 UAC |
| 数据位置 | 默认 `%LOCALAPPDATA%\CursorStudio\`，与安装目录无关；主题目录可在设置中更换；卸载不删数据 |
| 错误处理 | 中文主句说人话 + 括号内技术细节；绝不弹系统级崩溃框；顶层 ErrorBoundary 兜住渲染异常，给「重新加载」而不是白屏 |
| 安全 | 归档限额与条目名白名单、15 槽位白名单、光标文件路径包含、预览 8MB 上限、`dest_path` / 来源文件校验、主题 ID 与目录一致（决策 18）；外链只允许 `https://github.com`；检查更新 8 秒超时 |
| 稳定性 | 文件 / 注册表类命令全部后台执行；导入、备份、迁移互斥且进度可见；界面按动作显示 busy，失败一定释放（决策 19/20） |
| 无障碍 | 标题层级 h1 → h2 → h3；分段控件支持方向键 / Home / End；尊重 `prefers-reduced-motion`（含 `.ani` 停止播放）；装饰性预览图 `alt=""`；时间使用 `<time dateTime>`（决策 20） |
| 测试与 CI | 测试用临时目录与生成 fixture，不碰真实数据目录 / 光标设置；CI 跑 build、cargo test、design_audit、doc_ref_check（决策 21） |
| 性能 | 应用主题 < 500ms；预览单帧最长边 128px；预览源文件超过 8MB 时直接降级为空预览 |
| 国际化 | 仅简体中文 |
| 视觉 | 遵循 `design-system.md`；动效遵循 `motion.md` |

## 8. v1.0 → v2.0 作废项

| v1.0 写法 | 现状 | 依据 |
|---|---|---|
| 存储在 `Documents/MyCursorTool/Themes/` | `%LOCALAPPDATA%\CursorStudio\themes\` | 决策 1（避免被 OneDrive 同步、避免污染"文档"） |
| `SPIF_UPDATEINIFILE \| SPIF_SENDCHANGE` | 只 `SPIF_SENDCHANGE` | 实测带 UPDATEINIFILE 返回 `0x80070006` |
| 光标槽位 12 / 14 项 | **15 项**，顺序固定 | 决策 3 / `SLOT_DEFS` |
| `.ani` 转 GIF 存盘（方案 A） | Rust 提帧 → base64 → canvas | 决策 4 |
| 支持文件夹导入 | 已恢复：整个文件夹拖进窗口即可，与 zip 同一条落盘流程（决策 16，2026-10-24） |
| 同名主题询问"覆盖还是重命名" | 不询问，各自独立 UUID 共存 | §2 约束 |
| 解析 `.inf` 映射 | 已实现：`.inf` 优先于文件名推断（决策 15，2026-10-24） |
| `theme.json` 保存绝对槽位路径 | 已改为**磁盘存相对、运行时拼绝对**，旧绝对路径兼容读取（决策 17，2026-10-25） |
| 换主题目录直接搬文件、失败尽力恢复 | 改为预检 + 暂存复制 + 内容校验 + 原子切换 + 完整回滚（决策 17，2026-10-25） |
| 自制方案 / 单光标替换 | **不做**（2026-10-22 拍板） | 决策 10 |
| 写入数据库 | JSON 文件（`theme.json` / `history.json`） | 决策 1、决策 8 |
| 32 位与 64 位均支持 | x64 | 构建目标 |
| 拖拽 `.zip` 导入未实现 | 已实现：全窗口拖放 + 反馈遮罩，与对话框共用 `import_theme` | 2026-10-22 |
| 只限制 zip 体积、解压后不设上限 | 主题包 / 备份 / 文件夹统一限额 + 流式复制 + 条目名白名单，超限清理临时产物（决策 18，2026-10-25） |
| 同步命令直接在主线程读写磁盘 | 所有 I/O 命令 `spawn_blocking`，导入 / 备份 / 迁移发进度事件并互斥（决策 19，2026-10-25） |
| 测试直接改用户光标与 `%LOCALAPPDATA%` | 临时目录 + fixture + `CursorStudio.Tests` 隔离键；CI 四道闸（决策 21，2026-10-25） |
