## 鼠标光标主题管理工具 — 功能需求文档

**版本**：v1.0
**日期**：2026-06-17
**状态**：草稿

------

### 一、皮肤导入模块

#### 1.1 功能概述

用户可通过"导入主题"入口，将外部制作的鼠标主题包导入到本软件进行统一管理。支持 `.zip` 压缩包和本地文件夹两种导入方式。

#### 1.2 交互流程

1. 用户点击主界面"导入主题"按钮。
2. 弹出文件选择器，支持选择 `.zip` 文件或整个文件夹。
3. 软件在后台完成解析与导入，导入完成后主题出现在皮肤列表中。
4. 若导入失败，弹出错误提示，说明具体原因（格式不支持 / 无有效文件 / 文件损坏等）。

#### 1.3 后台处理逻辑

| 步骤         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| 解压与扫描   | 若为 `.zip`，先解压到临时目录；扫描目录内所有 `.cur`（静态）和 `.ani`（动态）格式文件。若未发现任何有效光标文件，终止并报错。 |
| 读取配置文件 | 检查目录内是否存在 `.inf` 配置文件。若存在，解析其中的光标槽位映射关系（如"Arrow=pointer.cur"）。若不存在，自动扫描所有光标文件，按文件名关键字（arrow、wait、hand 等）推断槽位，生成内部配置字典。 |
| 文件存储     | 将光标文件和配置字典统一复制到软件数据目录：`Documents/MyCursorTool/Themes/<主题名>/`，主题名默认取文件夹名或 zip 文件名，若重名则自动追加序号。 |
| 配置持久化   | 将主题元数据（名称、路径、槽位映射、导入时间）写入本地数据库或配置文件。 |

#### 1.4 约束与边界条件

- 同名主题导入时，询问用户是覆盖还是重命名。
- 单次导入文件总大小建议限制在 50 MB 以内，超出给出警告。
- 临时解压目录在导入完成或失败后自动清理。

### 二、皮肤列表与预览模块

#### 2.1 功能概述

主界面集中展示所有已导入主题，用户可浏览、选择，并实时预览该主题中各光标状态的外观。

#### 2.2 界面布局

- **左侧 / 中部**：主题列表区，以卡片或列表形式排列，每项显示主题名称、缩略图（取"普通箭头"状态图标）、导入日期。
- **右侧**：预览区，展示当前选中主题的所有已映射光标状态。

#### 2.3 预览规格

需展示的光标状态（Windows 标准槽位）：

| 状态名                                            | 说明       |
| ------------------------------------------------- | ---------- |
| 普通选择（Arrow）                                 | 默认指针   |
| 忙碌（Wait）                                      | 系统处理中 |
| 后台工作（AppStarting）                           | 程序加载中 |
| 文本选择（IBeam）                                 | 文字输入   |
| 链接选择（Hand）                                  | 超链接悬停 |
| 精确选择（Cross）                                 | 精细操作   |
| 移动（SizeAll）                                   | 窗口拖动   |
| 调整大小（SizeNS / SizeWE / SizeNWSE / SizeNESW） | 边框缩放   |
| 不可用（No）                                      | 禁止操作   |

#### 2.4 动态光标（.ani）预览方案

普通图片控件无法直接播放 `.ani` 动态光标，采用以下方案处理：

- **方案 A（推荐）**：导入时预处理，将 `.ani` 文件提取各帧并转换为 GIF，存储于主题目录，预览时直接播放 GIF。
- **方案 B（降级）**：若转换失败或不支持，展示 `.ani` 第一帧静态图，右下角标注"动态"角标。

#### 2.5 列表操作

每个主题项支持：重命名、删除、导出（重新打包为 `.zip`）。

### 三、主题应用模块

#### 3.1 功能概述

用户在预览确认后，一键将选中主题应用为当前系统鼠标光标方案，无需重启，立即生效。

#### 3.2 交互流程

1. 用户在主题列表中选中目标主题。
2. 点击"应用此主题"按钮（主界面显著位置）。
3. 软件后台执行应用逻辑，完成后按钮状态变为"当前使用中"，并在列表中高亮标记。
4. 若应用失败（权限不足等），弹出错误提示并给出解决建议。

#### 3.3 后台应用逻辑

```
1. 读取主题配置字典，获取各槽位对应的 .cur / .ani 文件绝对路径。
2. 写入注册表：
   HKEY_CURRENT_USER\Control Panel\Cursors
   按槽位名称逐一设置对应文件路径。
3. 调用 Windows API：
   SystemParametersInfo(SPI_SETCURSORS, 0, NULL, SPIF_UPDATEINIFILE | SPIF_SENDCHANGE)
   使变更立即在系统范围内生效，无需注销。
4. 将当前应用的主题名写入软件配置，下次启动时恢复高亮状态。
```

#### 3.4 权限说明

- 修改 `HKEY_CURRENT_USER` 注册表键不需要管理员权限，普通用户即可执行。
- 不涉及系统级注册表路径，无需 UAC 提权。

#### 3.5 恢复默认

提供"恢复系统默认"快捷入口，将注册表各槽位值清空，调用同一 API 通知系统刷新，恢复 Windows 原始光标。

### 四、指针自定义模块

#### 4.1 功能概述

用户可以不依赖现成主题包，自行为每个光标状态单独指定图片或光标文件，组合成一个专属自制方案。

#### 4.2 交互流程

1. 用户点击"新建自制方案"，输入方案名称。
2. 进入编辑界面，界面以表格或卡片形式列出所有光标槽位（参考第二章状态表）。
3. 用户点击任意槽位的"上传"区域，弹出文件选择器，支持格式：`.cur`、`.ani`、`.png`、`.jpg`、`.bmp`。
4. 上传图片类文件后，软件自动将其转换为 `.cur` 格式（取图片中心或左上角作为热点）。
5. 未指定的槽位保持空白（应用时该槽位使用系统默认值）或可选择继承某个已有主题的对应槽位。
6. 点击"保存方案"，完成创建；该方案随即出现在主题列表中，可正常预览与应用。

#### 4.3 后台处理逻辑

| 步骤     | 描述                                                         |
| -------- | ------------------------------------------------------------ |
| 文件接收 | 将用户上传的各槽位文件临时缓存。                             |
| 格式转换 | 非 `.cur` / `.ani` 的图片文件，调用转换库生成对应 `.cur` 文件，热点坐标默认为 (0, 0)，并提供手动调整入口。 |
| 目录打包 | 在 `Documents/MyCursorTool/Themes/<方案名>/` 下创建目录，将所有处理后的光标文件写入。 |
| 配置生成 | 自动生成该方案的槽位映射配置字典，写入数据库或本地配置文件，与导入主题的数据结构保持一致。 |

#### 4.4 编辑已有自制方案

已保存的自制方案支持再次进入编辑模式，单独替换某个槽位的文件，保存后覆盖原方案（版本历史可选支持）。

### 五、非功能性要求（通用）

| 类别     | 要求                                                         |
| -------- | ------------------------------------------------------------ |
| 兼容性   | Windows 10 / 11，32位与64位均支持                            |
| 性能     | 主题切换（应用）操作响应时间 < 500 ms                        |
| 存储     | 主题数据存储在用户 Documents 目录，不依赖软件安装路径，卸载软件后数据保留 |
| 错误处理 | 所有异常操作给出明确中文提示，不弹出系统级崩溃对话框         |
| 国际化   | 当前版本仅需支持简体中文界面                                 |
