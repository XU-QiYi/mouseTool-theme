## 09:12 真因锁定：SPIF_UPDATEINIFILE 是元凶（问题已解决）

用户运行 `diag_spi.exe`（普通 exe）得到决定性对比：
```
[1] SPI_GETCURSORSHADOW 读      Ok(())        ← 通道正常
[2] SPI_GETMOUSEVANISH 读       Ok(())        ← 通道正常
[3] SPI_SETCURSORS flags=3      Err(0x80070006 句柄无效)
[4] SPI_SETCURSORS flags=2      Ok(())        ← 成功！
[5] UpdatePerUserSystemParameters 返回 0      ← 无用
```

`3 = SPIF_UPDATEINIFILE(1) | SPIF_SENDCHANGE(2)`，`2 = 仅 SPIF_SENDCHANGE`。
→ **`SPIF_UPDATEINIFILE` 会让系统回写用户配置，本机该步骤拿不到句柄，导致整个调用失败。**

### 修复
`refresh_cursors()` 改为只传 `SPIF_SENDCHANGE`。因为光标路径已由 `write_cursors` 直接写入注册表，刷新阶段无需再让系统回写。

### 结果

## 09:17 🎉 白屏已解决：WebView2 沙箱初始化失败

### 根因
`tauri.conf.json` 的 window 配置加 `"additionalBrowserArgs": "--no-sandbox"` 后界面**立即恢复正常渲染**，连 `.ani` 预览图都正常显示。

**关键知识（踩过的最大坑）**：Tauri 自己会设置 `additionalBrowserArgs`，**这会覆盖 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` 环境变量**。之前所有通过环境变量传 `--disable-gpu` / `--force-device-scale-factor=1` / `--disable-features=...` 的测试**全部无效**，因为它们根本没传给 WebView2。必须在 tauri.conf.json 里配置才生效。

### 试过的配置参数（配置层，逐个单变量）
| 参数 | 结果 |
|---|---|
| `--disable-gpu` | 仍白屏 |
| `--no-sandbox` | **正常渲染** ✅ |

### 当前 tauri.conf.json 状态
```json
{
  "decorations": true,
  "transparent": false,
  "additionalBrowserArgs": "--no-sandbox"
}
```

### 待办
- `--no-sandbox` 降低了 Chromium 沙箱保护，对纯本地页面风险可控；后续可尝试更精确的 `--disable-gpu-sandbox` 之类，找出最小必要参数

## 10:05 修复：切换导航导致整页空白（Zustand selector 陷阱）

### 现象
点「已导入」/「最近使用」后整个页面变白，连侧边栏都消失；之后导航按钮全部失效。

### 真因
CDP 抓到：
```
The result of getSnapshot should be cached to avoid an infinite loop
Maximum update depth exceeded.
```
`selectFilteredThemes` 在 **selector 里做 filter**，每次返回新数组引用；zustand 用 `Object.is` 比较快照 → 永远不相等 → 无限重渲染 → React 抛错并卸载整棵树。「主题图库」页不崩是因为无搜索词时直接返回 `s.themes` 原引用。

### 修复
- `themeStore`：`selectFilteredThemes(store)` → 纯函数 `filterThemes(themes, page, query)`
- `ThemeList`：`useThemeStore((s) => s.themes)` 取稳定引用 + `useMemo(() => filterThemes(...))`
- 「最近使用」同样路径

### 同时按用户要求加占位页
`App.tsx` 新增 `PlaceholderPage`：`currentPage !== "library"` 时右侧显示图标 + 标题 + 说明 + 「功能开发中」徽章（已导入 / 最近使用各一份文案）。侧边栏与中间列表始终保留。

### 验证
`scripts/nav_check.mjs`（新增，CDP 依次点击三个导航项）：三栏结构完整，无异常输出
- 已导入：ASIDE 224 / SECTION 288「还没有导入过主题」/ SECTION 658「已导入的主题…功能开发中」
- 最近使用：同上结构
- 主题图库：恢复卡片列表

### 规范（重要）
**不要在 zustand selector 里返回新对象/新数组**。派生数据一律写成纯函数 + 组件内 `useMemo`；否则会触发无限重渲染并整页崩溃。
